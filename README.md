- Firebase CLI

   ```sh
   git clone https://github.com/justchillac/VIBE.git
   cd your-repo

2. Install dependencies:
   ```sh
   npm install
   ```
   or
   ```sh
   yarn install

3. Set up Firebase:
   ```sh

   firebase init

### Running the project
To start the development server:
   ```sh
   npm start
   ```
   or 
   ```sh
   yarn start
   ```

   ```sh
   npm run build
   ```
